
#Ferramentas para automatizar a instalação e compilação do **QSocket** e a execução do **GSocket** em dispositivos Android com Termux (AArch64).

# Projetos

- [QSocket](https://github.com/qsocket/qsocket)
- [GSocket](https://gsocket.io/)

## Requisitos

- Python
- Git

## antes de instalar:

- pkg update && pkg upgrade -y
- pkg install python -y

## Compatibilidade

Testado em Termux com arquitetura AArch64.
